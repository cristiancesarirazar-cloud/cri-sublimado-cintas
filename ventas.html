Respaldo de datos

Los datos se guardan en este navegador del celular. No se sincronizan automáticamente con otros teléfonos. Descargá un respaldo con frecuencia y no borres los datos del navegador sin exportarlos.

Privacidad

Esta versión guarda las ventas, productos y gastos en el almacenamiento local del navegador. Cualquier persona que use este mismo navegador y dispositivo podría verlos. Para mantenerlos, exportá el respaldo antes de cambiar de navegador o dispositivo.
